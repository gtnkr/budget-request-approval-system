# โครงสร้างงานพรีเซนต์ 2 คน

เอกสารนี้แบ่งหน้าที่ช่วงแรกไว้สำหรับสมาชิกคนที่ 1 และ 2 เท่านั้น ไม่ย้ายฟังก์ชันหลักหรือเปลี่ยนการทำงานของระบบ

## สมาชิกคนที่ 1 — ระบบล็อกอิน
- ไฟล์หลัก: `src/App.tsx`
- เนื้อหา: บัญชีทดลองทั้งหมด การกรอกชื่อผู้ใช้ รหัสผ่าน การตรวจล็อกอิน การเก็บผู้ใช้ใน sessionStorage และปุ่มออกจากระบบ
- รหัสผ่านทดลอง: `demo1234`

## สมาชิกคนที่ 2 — ฟอร์มสร้างคำขอใหม่
- ไฟล์หลัก: `src/Dashboard.tsx`
- เนื้อหา: ข้อมูลรายการ ประเภทงบ วงเงิน รายการค่าใช้จ่าย ผู้รับเงิน เอกสาร และปุ่มบันทึกหรือส่งอนุมัติ
- มาร์กเกอร์ในโค้ด: `ส่วนที่ 2.1` ถึง `ส่วนที่ 2.6`

## ขอบเขตของโค้ด
ระบบยังใช้ไฟล์เดิม `src/App.tsx` และ `src/Dashboard.tsx` โดยมีคอมเมนต์ชี้จุดพรีเซนต์สองส่วนนี้
สามารถเพิ่มสมาชิกคนที่ 3 เป็นต้นไปภายหลังโดยไม่ต้องแก้โครงสร้างฐานของทั้งโปรเจกต์
